# 總體經濟與景氣循環分析 Agent Skill

> 讓 AI 助理以**景氣循環四階段框架**與**經濟指標實證**，產出總體經濟與景氣分析報告的 Agent Skill。

以經濟數據為唯一證據，判讀景氣現況、所處階段與趨勢，並輸出資產配置方向指引。

---

## 用途

本技能以經濟數據為依據，判讀景氣現況、所處階段與趨勢，並產出結構化分析報告。安裝後可用它完成以下工作：

- **定位景氣階段、預判趨勢**：判斷目前是復甦、成長、榮景（初期／後期轉折期）或衰退期，並給出未來 3~6 個月、6~12 個月的方向判斷與信心水準
- **回答關鍵問題**：景氣何時落底或反轉、某個經濟指標的變化代表什麼、現階段資產配置方向該如何調整
- **結論有憑有據**：每個判定都附可查證的數據錨點（指標｜數值｜期間｜官方來源），查不到就誠實標示「無法判定」，絕不編造數字或以推論搪塞
- **不被市場敘事帶著走**：先依經濟數據獨立判定，市場觀點最後才另闢一節呈現，供你對照參考
- **一份可直接閱讀的報告**：九節結構化報告，附推理鏈、反面指標與風險聲明，省下自行整理零散對話的時間

分析對象涵蓋**美國**與**台灣**（另含印度、日本等區域市場與地緣政治情境）；資產配置部分提供一般性方向指引。

## 理論基礎

本技能的理論體系以**愛榭克《景氣循環投資》**一書的景氣循環投資框架為基礎，包含：

- **兩大長週期**：生產力擴張循環 vs 通膨擴張循環（含人口結構長週期視角）
- **景氣循環四階段**：復甦期 → 成長期 → 榮景期（細分初期／後期〔景氣轉折期〕）→ 衰退期，各階段的現象、確認指標與配置方向
- **基期效應原理**：YoY 數據判讀前必查的高低基期規律
- **景氣轉折九大指標**：殖利率倒掛、初領失業救濟金、油價、民間消費、消費者信心、耐久財訂單、政府支出、庫存增減、債務違約率

並**補充部分總體經濟指標**作為理論體系的延伸與操作。

## 功能特色

- **四階段判讀框架**：復甦／成長／榮景／衰退，各附關鍵指標與一般性配置方向
- **三層漏斗式查證**：快篩 5 項必查（初領失業救濟金、ISM PMI、零售銷售 YoY、10Y-2Y 利差、GDPNow）→ 假說確認組 3~6 項 → 專項補充；典型查詢量約 8~11 項
- **證據分級制度**：A 級官方統計、B 級官方即時預估、C 級市場定價數據、D 級分析師預測（不可作判定證據）
- **防挑軟柿子規則**：確認指標須涵蓋就業／消費／投資／金融等不同面向，反證與矛盾證據必須完整揭露

```bash
npx skills add JasonMMIV/macro-economy-analysis-skill --skill macro-economy-analysis
```

## 使用方式

安裝後直接以自然語言提出總經／景氣問題即可觸發，例如：

- 「分析目前美國景氣處於哪個階段？」
- 「現在是不是榮景後期？幫我掃描景氣轉折九大指標。」
- 「台股的景氣現況與未來兩季展望。」
- 「初領失業救濟金人數創新低，這代表什麼？」
- 「從總經角度判讀金價走勢。」
- 「幫我做一次全面的景氣體檢。」

### 報告輸出結構

技能會依標準模板輸出九節報告：

1. **結論摘要**——階段判定（含信心水準）、長週期定位、3~6 個月／6~12 個月方向
2. **證據儀表板**——本次已查證指標一覽（含來源、期間、方向、基期高低）
3. **指標判讀詳述**——數據 → 規則 → 推論 → 小結的顯性推理鏈
4. **階段判定與轉折警訊**——支持與反對證據完整列示
5. **趨勢判斷與推理鏈**——各附信心水準與「反面指標」（什麼數據會推翻判斷）
6. **風險情境與結構性因素**——地緣政治壓力測試、外生衝擊聲明
7. **資產配置意涵**——一般性方向（非投資建議、不含任何具體標的）
8. **市場觀點與市場情緒**——供你參考的資訊，不回頭影響判定
9. **不確定性與數據缺口**——未取得的數據、可推翻條件、信心限制

## 核心原則摘要

| 原則       | 內容                                                                               |
| ----------- | ----------------------------------------------------------------------------------- |
| 證據優先   | 無數據，不下結論；缺資料寫「無法判定」；禁止編造數字；模型記憶中的舊數字不可當現況 |
| 防定錨     | 判定趨勢時禁止參考市場觀點，完成數據判定後才呈現市場觀點給使用者                   |
| 不機械套用 | 綜合判斷、不設數量門檻；依貨幣政策環境、地緣政治、所處長週期調整                   |
| 誠實聲明   | 風險事件（泡沫破裂、疫情、戰爭）無法以指標預判，報告必含外生衝擊聲明               |
