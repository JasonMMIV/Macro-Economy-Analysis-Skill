# 參考：理論框架與景氣循環四階段

> 本檔為 macro-economy-analysis skill 的參考文件（理論框架），完全自足。

## 1. 長週期理論

### 1.1 人口結構與經濟增長

- 美國增長動能主要來自內需，人口結構是內需重要驅動力之一。
  - 10~25 歲：消費、創新
  - 25~40 歲：貸款買車、買房
- 生育潮後 10~25 年 → 生產力擴張循環
- 生育潮後 25~40 年 → 通膨擴張循環（持續約生育潮的一半）→ 房價快速增長 → 房地產泡沫
- **適用限制**：人口結構是長週期的有用視角但非唯一驅動力；技術創新（TFP）、制度政策、國際資本流動、金融信用創造同樣重要。此為歷史傾向，非機械定律。
- 資料來源：美國 CDC 逐年出生人口數。

### 1.2 景氣循環兩大長週期

| | 生產力擴張循環 | 通膨擴張循環 |
| --- | --- | --- |
| 觸發條件 | 生產技術跳躍式革新 → 勞動生產力大增 | 生產力週期成熟 → 過度生產與競爭 → 資金流入實體資產 |
| 特徵 | 綿長強勁的經濟擴張 | 房市、黃金、原油大漲；股市漲幅小、回落大 |
| 投資重點 | 資本市場（股市） | 通膨相關資產（原物料、房地產、黃金） |
| 觀察指標 | 研發總額佔 GDP 比值呈上升趨勢 | 實體資產相對走強 |

週期轉換時（無論生產力→通膨 或 通膨→生產力），資本市場回落幅度較大。

### 1.3 AI 生產力循環修正（⚠ 分析師假說，未經驗證）

- 核心論點：AI 導入顯著提升生產力，企業可付更高薪資同時維持利潤率，打破「薪資-通膨螺旋」，延長擴張期（Goldilocks）。
- 週期預測（分析師觀點）：擴張可能延續至 2027~2028 年附近——高度依賴 AI 效益實現速度與規模，不確定性高。
- 反面論點：AI 效益集中特定產業未廣泛擴散；重大技術革命滲透常需 10-20 年；AI 投資若成泡沫反而加速反轉；地緣政治（晶片管制）可能中斷路徑。
- **引用規則**：討論此假說時必須一併標註其未驗證與爭議性，不得當成既定事實。

### 1.4 基期效應原理（判讀 YoY 前必查）

- 低基期：數據不再惡化，自然回升；高基期：無法再創高，自然面臨衰退。
- 用途：判斷趨勢轉折、理解 YoY 自然回歸、避免把短期波動誤判為趨勢反轉。

### 1.5 美國家庭財務結構

- 儲蓄率低、負債導向、對利率上升高度敏感；利率上升可能迅速降低消費。
- 意涵：升息對消費抑制效果顯著；消費信貸條件變化是重要領先指標。

## 2. 景氣循環四階段

### 2.0 總覽

| 階段 | 主要特徵 | 一般性配置方向 |
| --- | --- | --- |
| 復甦期 | 貨幣寬鬆極致、財政刺激、低基期反彈 | 最佳布局時機，勇敢做多 |
| 成長期 | 遞延消費釋放、就業改善、投資擴張 | 安心長線持有 |
| 榮景期 | 透支消費、過熱投資、風險低估（分初期／後期〔轉折期〕，見 2.3） | 逐年降低持股，提高避險 |
| 衰退期 | 快速降溫、市場急凍、悲觀瀰漫 | 持有債券與美元，把握低檔布局 |

> 注意：上述為一般性方向指引，須依貨幣政策環境、地緣政治、所處長週期調整，不宜機械式套用。

### 2.1 復甦期（核心問題：落底是否確立？回升力道如何？）

四大現象與正確解讀：

| 現象 | 錯誤迷思 | 正確解讀 |
| --- | --- | --- |
| 貨幣政策寬鬆走向極致 | 貨幣政策恐無效 | 貨幣政策終將發威 |
| 財政刺激政策陸續推出 | 政府債臺高築拖垮經濟 | 藏債於政府、藏富於民 |
| 油價原物料處於谷底 | 價格將導致通縮 | 低廉價格刺激需求恢復 |
| 經濟數據處於極低基期 | 最壞時候還沒來 | 低基期走完，數據將顯著反彈 |

關鍵指標：

- 利率：聯邦基金利率、10Y 公債殖利率、30 年房貸利率
- 就業：**初領失業救濟金人數**（高峰期＝復甦期起點）；短期失業人數（失業<5 週，高點反轉＝就業回春）
- 消費：零售銷售 YoY、耐久財消費支出 YoY（領先指標：榮景期早於消費走疲、衰退期提早落底）
- 投資：私人固定資本投資 YoY、製造業耐久財新訂單 YoY（耐久財訂單落底 → 投資動能回溫）
- 進口金額 YoY 回溫 → 景氣復甦

配置方向：股＝勇敢布局；債＝無風險債價格高點宜轉股；原物料＝生產力循環短線行情、通膨循環延續至成長榮景；金＝一般趨弱宜減持，但若伴隨大規模 QE（如 2020）金價仍可能強勢，須依實質利率判斷。

### 2.2 成長期（核心問題：是否穩定擴張？消費投資良性循環？）

四大現象：

1. 樽節結束，遞延消費挹注內需（儲蓄率於復甦期上升、成長期釋放）
2. 就業增長顯著改善（非農明顯提升、初領下降）
3. 民間投資擴張（固定資本投資 YoY 優於復甦期、住宅投資 YoY 持續上揚）
4. 通膨回升至可持續水準 →「投資→消費→再投資→再消費」良性循環

配置方向：股＝做多、拉回做多、買進持有；無風險債＝避免（升息＋資金磁吸）；高收益債＝可持有；原物料＝初期上揚後期走跌（生產力循環）；房地產＝穩健增長可持有。

### 2.3 榮景期（核心問題：透支消費是否過熱？轉折警訊？）

四大特徵：加速成長、資本市場熱絡、樂觀情緒高昂、風險意識極度低估。

**榮景期分兩階段，指標用途嚴格區分**：

| 階段 | 判別指標 | 用途 |
| --- | --- | --- |
| 榮景期初期 | 進入指標：透支消費（民間投資潮為進一步確認） | 確認「進入」榮景期 |
| 榮景期後期（景氣轉折期） | 景氣轉折九大指標 | 判別榮景「即將結束」、衰退將至 |

> **關鍵辨析（常見誤解）**：九大轉折指標**不是**進入榮景期的確認指標，而是「榮景期後期（景氣轉折期）」的判別指標——出現代表榮景即將結束、衰退將至。進入榮景期只看下列進入指標。

#### 2.3.1 榮景期初期：進入指標（透支消費出現即確認進入榮景期）

1. 透支消費（確認指標）：實質個人消費支出 YoY > 實質可支配個人收入 YoY —— 出現即確認進入榮景期
2. 民間投資潮（進一步確認）：私人固定資本投資 YoY 顯著上升；OECD 美國製造業信心指數 > 100 —— 僅作進一步確認；單獨出現而無透支消費，仍不算榮景期

#### 2.3.2 榮景期後期（景氣轉折期）：景氣轉折九大指標

> 判讀方式：九大指標依各自判讀陳述（如殖利率倒掛出現＝景氣已入後期），逐項如實呈現出現與否及其含義；不設「出現幾項才算轉折期」的數量門檻。

| 指標 | 判讀 |
| --- | --- |
| 殖利率倒掛（10Y-2Y） | 市場定價衰退風險上升，景氣已入後期 |
| 初領失業救濟金 | U 型確立 → 衰退將至；1 年內再創低點 → 榮景可延長至少 3 季 |
| 油價 | 長期走升 → 實質購買力下降 → 擊垮內需動能 |
| 民間消費 | 零售銷售率先走疲；消費 YoY 自高點反轉 |
| 消費者信心指數 | 創新高後 3~6 個月 S&P 500 創新高；尾聲反轉 |
| 耐久財訂單 | 二度衝高 → 榮景即將結束 |
| 政府支出 | 州和地方政府支出 YoY 顯著增加，於衰退前後自高點轉向 |
| 庫存增減 | 完整循環約 3 次明顯庫存增加（復甦、成長、榮景） |
| 債務違約率 | 中期後提升 → 景氣恐將惡化 |

> 注意：風險事件造成的衰退無法以指標預判（2000 網路泡沫、2020 疫情），故榮景期操作宜謹慎；但殖利率倒掛通常仍能預示景氣接近衰退。

配置方向：股＝逐步減持高風險部位、轉防禦股（醫療保健、必需消費、高品質高現金流）、上調停損、逐年減少持股；無風險債＝升息結束後布 5~7 成長債；高收益債＝避免；原物料＝尾聲低利率與弱勢美元推升油價，隨後於衰退期大跌。

### 2.4 衰退期（核心問題：轉折是否確立？何時落底？）

三階段演進：轉弱 → 加速 → 落底。

確認衰退：

- 消費陡降：實質個人消費支出 YoY 出現 2 次陡降（連續 4 季下滑算一次）；第 5 季若繼續下修 → 急速惡化
- 民間投資反轉：投資衰退週期領先 GDP 1~2 季；衰退 >10% 深度 → 股市大跌

判斷落底（趨勢用 YoY、落底用 SAAR）：

| 指標 | 落底信號 |
| --- | --- |
| 民間投資 | 實質民間投資季增年率谷底反轉 |
| 設備支出 | 可能率先落底反彈 |
| 民間消費 | 實質零售銷售月增年率止跌回升 |
| ISM 製造業指數 | 止跌回升為落底信號 |

配置方向：股＝絕佳入市時機、分批進場完成 U 型微笑曲線；無風險債＝資金湧入債多頭；高收益債＝初期大跌可布局、落底後快速回升；美元＝衰退期走強（生產力循環長期多頭、通膨循環盤整或空頭）。

> 風險提示：「分批進場」前提是確實處於落底階段。若衰退深度超乎預期（如系統性金融危機），市場可能持續下探遠超一般衰退，過早進場將面臨重大虧損。務必搭配落底指標確認，嚴格控制單次投入比例。

## 3. 通膨與衰退的規律

- 榮景期進入衰退期前，通膨總是再度升溫。
- 油價下跌有利維持消費動能；油價長期走升削弱內需。
- 榮景結束前信號：升息循環結束＋銀行放貸增長自高點下滑＋放貸違約率自低點反轉向上。
