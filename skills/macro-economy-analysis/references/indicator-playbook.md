# 參考：經濟指標判讀手冊

> 本檔為 macro-economy-analysis skill 的參考文件（指標判讀與資料來源），完全自足。

## 1. 指標綜合排序（依時效與準確性）

| 優先序 | 指標 | 說明 |
| --- | --- | --- |
| 1 | 初領失業救濟金人數（Initial Claims） | 最即時 |
| 2 | 台經院製造業營業氣候測驗點／製造業 PMI 未來六個月展望 | 景氣預測效果佳 |
| 3 | ISM PMI | 景氣方向參考 |
| 4 | 零售銷售 | 民間消費動能 |
| 5 | 企業獲利前瞻 | |
| 6 | GDP 預測／GDPNow | |
| 7 | 企業獲利 | 公布晚 |
| 8 | 企業貸款違約率 | 確認衰退 |

**可預測景氣衰退期的指標**：初領失業救濟金、企業貸款違約率。

---

## 2. 就業市場

### 2.1 初領失業救濟金人數（最重要、最即時）

| 特性 | 說明 |
| --- | --- |
| 公布頻率 | 每週 |
| 時效性 | 極高，最即時的就業數據 |
| 與股市關聯 | 強，多數些微領先股市，偶爾落後 |
| 與 GDP | 與 GDP YoY 走勢高度接近 |
| 轉折確認 | 股市與 Initial Claims 同步轉折時，趨勢確立 |

判讀：高峰期 → 復甦期起點；U 型結構確立 → 衰退期將至；1 年內再創低點 → 榮景可延長至少 3 季。

### 2.2 非農就業新增職缺數

- 與經濟成長連動性高，為確認就業趨勢的重要指標。

---

## 3. 消費與零售

### 零售銷售

| 特性 | 說明 |
| --- | --- |
| GDP 占比 | 民間消費占美國 GDP 近 7 成 |
| 公布頻率 | 每月 |
| 與 GDP | 零售銷售 YoY 與 GDP YoY 走勢大致相符 |
| 數據特性 | 波動較大 |
| 與股市 | 關聯強，但股市大跌時零售銷售可能僅持平 |

判讀：銷售額與 YoY 交互參照確認走勢；為領先指標，榮景期早於民間消費走疲、衰退期提早落底反轉。

---

## 4. 製造業與 PMI

### 4.1 美國 ISM 製造業 PMI

- 與美股有一定關聯，但波動幅度與股價不成比例；時效性有時領先、有時落後。
- 庫存循環影響約 5% 以內波動；常可領先反映景氣反轉（2008 金融海嘯落底後提早反彈）。
- 與台股關聯度高，有時領先 1～2 個月，有時同時或落後，非絕對相關；庫存循環影響約 10%。
- 細項：**新訂單指數與客戶端存貨**對照，更能看出庫存循環週期。

### 4.2 美國 ISM 非製造業 NMI

- 反應較慢但波動較小；較不受製造業庫存循環影響；較能看出長期趨勢。
- 判讀：**PMI 與 NMI 先後大幅下行時，才能確認景氣衰退。**

### 4.3 台灣製造業 PMI

- 2020 前長期趨勢似乎領先美國製造業 PMI。
- 未來六個月展望與台經院營業氣候測驗點類似，景氣預測效果佳；與台股密切相關，有時領先股市；公布落後一個月。
- 傳導順序：台灣外銷訂單 → 台灣 PMI → 美國 PMI。
- 製造業週期觸頂反轉影響：台股 1～2 個月內大跌，1～4 個月內觸底，之後震盪中成長。

---

## 5. 房市指標（長期趨勢領先指標）

- HMI（建商信心）＝心理指標／領先指標
- Housing Starts（新屋開工）＝實際行動／供給指標
- New One Family Houses Sold（新屋銷售）＝最終成果／需求指標
- 經常領先反映長期經濟趨勢；景氣不一定馬上轉向，**需搭配就業數據確認**；對利率高度敏感（30 年房貸利率）。

---

## 6. 貨幣與流動性

### 6.1 貨幣基底（Monetary Base）

- 又稱準備貨幣、強力貨幣＝流通通貨＋銀行準備金。
- 關係：貨幣基礎（最具流動性）⊂ M2（＋儲蓄存款＋貨幣市場基金＋小額定存）。
- 歷史觀察：2008 起 QE 使基底不正常增加；**基底貨幣減少時，股市陷入震盪整理或修正**。

### 6.2 聯準會資產負債表

- 美國擴大資產負債表規模為股市上漲（跳階上漲）的重要力量。

---

## 7. 殖利率曲線（市場定價類指標）

### 10Y-2Y 倒掛

- 定義：10Y 殖利率 < 2Y 殖利率。正常曲線＝短 < 長；倒掛＝預期未來利率大幅下降。

倒掛的經濟意義：

1. 市場預期聯準會將大幅降息（短期高＝當前緊縮；長期低＝預期經濟弱）
2. 信貸壓力：銀行借短貸長利差壓縮 → 放貸意願降 → 融資難度升 → 經濟放緩
3. 市場定價「衰退風險」：避險需求推低 10Y

歷史關係（倒掛 → 衰退間隔）：1969→3 個月；1973→4；1978→18；1989→13；2000→12；2006→18；2019→6（疫情）；2022/7 起→新一輪樣本。過去 60 年，倒掛後美國通常在 6-24 個月內進入衰退。

**關鍵警戒：倒掛解除階段需高度警戒。** 衰退與股市大跌經常（非絕對）發生在「倒掛解除」階段（聯準會降息 → 短率急跌 → 利差由負轉正、曲線迅速陡峭化）。利差回正≠警報解除，反而應提高警覺。但時序關係並非完美規律，須搭配 Initial Claims、企業違約率等確認指標，避免單一指標過度判讀。

---

## 8. 企業獲利與違約率

- 企業獲利：有效指標，但公布時間晚、不即時；與 GDP YoY 走勢相關。
- 企業貸款違約率：與企業獲利同步，可用來確認景氣衰退；**中期後違約率提升 → 景氣恐將惡化**。

---

## 9. GDP 相關

- **GDPNow**（亞特蘭大聯儲即時預估）：與實質 GDP 季增率相近，領先一季，可預估下一季 GDP。
- **GDP 年度修訂**（每年 7～8 月）：修訂幅度 ∝ 未來半年波動幅度；調升 → 揚升多頭；調降 → 回檔。

---

## 10. 進階指標

### 10.1 耐久財消費（經濟擴張風向球）

強勁耐久財消費 → 鞏固民間固定資本支出信心 → 提高資本支出 → 拉動勞動生產力。

### 10.2 黃金與實質利率模型

- 關鍵指標：實質利率＝10Y 公債殖利率 − TIPS 隱含通膨率（或 CPI YoY）。
- 實質利率翻正／上揚 → 不利金價（聯準會強力升息或通膨快速降溫）。
- 實質利率轉負／下降 → 有利金價（持有現金或債券回報被通膨侵蝕）。
- 補充：此為主流框架之一，但 2022 後央行購金、地緣避險、去美元化等獨立影響日增，單一模型難以完整解釋金價。

### 10.3 高收益債利差（股市領先指標，市場定價）

- 定義：非投資等級債殖利率 − 同天期公債殖利率。
- 收斂（低位）＝流動性充裕、風險偏好高、擴張穩健；擴大（飆升）＝違約風險升、資金撤出風險資產。
- 策略：升息循環末端若經濟未見立即衰退，高票息非投資等級債具投資價值；利差異常擴大則轉防禦。

### 10.4 通膨細項：居住成本滯後性

- Shelter/Rent 佔 CPI 權重約 30-40%；滯後約 6-12 個月（部分研究：市場租金→官方 CPI 傳導中位數約 20 個月）。
- 應用：市場租金指數（如 Zillow Rent Index）已跌、官方 CPI 居住成本仍漲時，可預判 CPI 將因滯後效應補跌。

### 10.5 油價與消費動能

油價下跌有利維持消費動能；油價長期走升 → 實質購買力下降 → 擊垮內需動能。

### 10.6 銀行放貸與違約率（榮景結束前信號）

升息循環結束＋銀行放貸增長自高點下滑＋放貸違約率自低點反轉向上。

### 10.7 通膨與衰退

榮景期進入衰退期前，通膨總是再度升溫。

### 10.8 股市泡沫程度

席勒本益比（Shiller CAPE）＝市值／通膨調整後企業整體獲利 10 年平均值。（估值類指標，僅供衡量泡沫程度，不得作為景氣階段的唯一判斷依據。）
