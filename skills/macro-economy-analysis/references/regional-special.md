# 參考：區域市場、地緣政治與特殊情境

> 本檔為 macro-economy-analysis skill 的參考文件（區域與特殊情境），完全自足。

## 1. 台灣市場

### 1.1 經濟結構特性

- 高度依賴出口的小型開放經濟體；出口佔 GDP 比重最大。
- 外資持有台股市值達 4 成以上、每日交易額約佔 3 成、權值股持股可達 4～6 成。
- 全球景氣對台股資金挹注影響很大；**台股指數幾乎都跟著美股走**。

### 1.2 核心指標：外銷訂單

外銷訂單 YoY 與台股 YoY 呈極高度正相關，通常領先或同步於股市轉折：

| 訂單狀態 | 股市表現 |
| --- | --- |
| 訂單上行 | 股市走多頭 |
| 訂單下行至落底 | 股市陷入修正整理 |
| 訂單負成長 | 股市大跌 |

細項觀察：電子產品／資訊通信（反映全球科技業資本支出與終端需求）；訂單主要來源為美國和中國。

### 1.3 台經院營業氣候測驗點

具有良好景氣預測效果（指標優先序第 2 名）。

### 1.4 其他台灣指標

| 指標 | 意義 | 特性 |
| --- | --- | --- |
| 進口總值 | 內部投資與消費動能 | 復甦期領先～同時；衰退期落後 |
| 資本設備進口 | 未來投資動能 | 波動大，與股市關聯模糊 |
| 出口總值 | 外部需求 | 同時～落後 |
| 景氣對策信號 | 綜合景氣 | 同時指標，確認當前景氣狀態 |
| 外資淨匯入 | 外資對台股看法 | — |

### 1.5 匯率影響

| 新台幣 | 短期 | 中長期 |
| --- | --- | --- |
| 弱勢 | 外資出逃，股市易跌 | 有利外銷，進出口回溫後股市上漲 |
| 強勢 | 帶動資金行情 | 面臨回檔壓力 |

補充：長期弱勢有利外銷；後期進出口回溫（經濟數據與企業獲利以台幣計價），股市上漲。

### 1.6 美國相關指標（對台股影響）

美總體耐久財訂單、電腦與電子產品訂單、電子零組件訂單（同時～落後指標）。

## 2. 印度市場

- 核心邏輯：經濟快速發展階段，部分特徵似中國 1990-2000 起飛期，但國情差異重大。
- 驅動力：人口紅利（龐大年輕勞動力）；供應鏈重組（China+1）；基礎建設（Digital India 與實體基建）。
- 與中國起飛期關鍵差異：政府執行效率（聯邦制分歧、土地與勞動法改革緩慢）；基建起點不足（電力、物流待改善）；製造業占 GDP 偏低（約 13-15%，服務業導向）；外資環境複雜（監管限制多）。
- 投資定位：長期潛力可期但路徑更曲折耗時；波動較大，適合定期定額長期布局，密切關注改革落實與地緣風險。

## 3. 日本市場

- 核心邏輯：經濟結構根本性轉變，非單純貨幣寬鬆結果。
- 驅動力：通膨回歸（擺脫 30 年通縮心態、企業重啟國內投資、薪資增長）；公司治理改革（東證要求改善 P/B<1，迫使企業增配息、回購、提升 ROE）。

## 4. 地緣政治風險與投資影響

### 4.1 對台灣的結構性影響

- **外資撤離效應**：大國關係緊張 → 外資系統性降低台股配置 → 資金外流＋台幣貶值；外資持股逾四成，對指數衝擊顯著。
- **地緣政治折價**：台股估值倍數長期受地緣風險壓抑，基本面相近時本益比通常低於低風險市場。

### 4.2 一般傳導規律

| 傳導路徑 | 對資產影響 |
| --- | --- |
| 大國貿易衝突升級 | 全球貿易量萎縮 → 出口體外銷訂單下滑 → 股市承壓 |
| 能源產區衝突或制裁 | 油價急漲 → 通膨升 → 壓縮央行降息空間 → 壓抑消費動能 |
| 科技管制與供應鏈斷裂 | 半導體等關鍵產業供應受阻 → 相關供應鏈國家股匯市劇烈波動 |
| 避險情緒急升 | 資金湧入美元、美債、黃金 → 新興市場資金外流 |

### 4.3 操作原則

- **情境分析**：在景氣循環判斷外，額外設定「地緣衝突升級」壓力測試情境，評估持倉最大可能回撤。
- **分散配置**：避免過度集中於單一地緣風險熱點，跨區域分散降低尾部風險。
- **動態調整**：地緣風險指標升溫（外資加速匯出、軍事部署異動、貿易制裁擴大）時，適度提高現金與避險資產比重。

## 5. 特殊情境：Covid-19 長期結構性衝擊

核心論點：長新冠並非一次性衝擊，而是對經濟體質的「慢性病式」拖累，類似勞動力結構老化 → 潛在成長率下降＋通膨黏性增加。

### 5.1 總體經濟損失

- GDP 隱性成本：年度成本約佔 GDP 3-5%（醫療支出增加＋勞動產出損失）。
- 美國潛在 GDP 成長率恐永久性下修 0.3–0.5 個百分點。

### 5.2 勞動市場結構改變

1. 勞動參與率下降（健康因素提前退休／退出職場，難回疫情前高點）
2. 缺勤率上升（健康缺勤成常態，生產力受損、隱性營運成本增加）
3. 薪資通膨壓力（勞動供給受限 → 高薪搶人 → 加劇薪資-通膨螺旋風險）

### 5.3 投資判讀調整

| 影響層面 | 判讀調整 |
| --- | --- |
| 通膨預期 | 供給側受限，通膨更具黏性，聯準會降息空間可能受限 |
| 財政壓力 | 醫療與社福支出擴大，關注財政赤字與長債殖利率影響 |
| 產業選擇 | 避開高度依賴低階勞動力產業；相對看好醫療照護、自動化設備（取代人力）板塊 |
